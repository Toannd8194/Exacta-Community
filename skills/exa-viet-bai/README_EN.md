# exa-viet-bai — Exacta · Viết bài

[Tiếng Việt](README.md)

## What it does

Drafts or restructures English manuscript sections from Vietnamese notes, drafts, or theses, keeping the author's evidence and adding a Vietnamese author check.

Vietnamese overlay for [`nature-writing`](../nature-writing/README_EN.md): loads the base skill, then applies Vietnamese rules.

## Example prompt

```text
Use exa-viet-bai to draft an English introduction from my Vietnamese notes and thesis chapter.
```

## Shared rules

- Instructions are English; conversation with the user is Vietnamese.
- No manuscript or patient data is sent to external services.
- No invented data, references, or approval numbers; gaps are marked `[CẦN BỔ SUNG: ...]`.
- Full rules: [AGENTS.md](../../AGENTS.md).
