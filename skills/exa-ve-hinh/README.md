# exa-ve-hinh — Vẽ hình bài báo và luận văn

[English](README_EN.md)

## Chức năng

Vẽ, sửa hoặc rà soát hình cho bài báo và luận văn bằng Python hoặc R, chạy hoàn toàn trên máy: Kaplan–Meier, forest plot, ROC, sơ đồ chọn mẫu CONSORT/STROBE, Bland–Altman; hỗ trợ nhãn tiếng Việt có dấu, dấu thập phân phẩy, đánh số theo chương.

Lớp phủ tiếng Việt của [`nature-figure`](../nature-figure/README_EN.md): nạp skill gốc rồi áp dụng các quy tắc tiếng Việt.

## Ví dụ sử dụng

```text
Vẽ biểu đồ ROC cho xét nghiệm X, đánh dấu điểm cắt Youden, nhãn tiếng Việt cho luận văn.
```
