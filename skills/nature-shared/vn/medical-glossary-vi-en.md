# Vietnamese–English Medical Research Glossary

Standard term pairs for clinical and public-health research. Use the English column in English
manuscripts and the Vietnamese column in Vietnamese documents. Add project-specific terms to the
Terminology Ledger, not to this file.

## Study design

| Tiếng Việt | English |
|---|---|
| Nghiên cứu mô tả cắt ngang | Cross-sectional descriptive study |
| Nghiên cứu cắt ngang có phân tích | Analytical cross-sectional study |
| Nghiên cứu bệnh – chứng | Case–control study |
| Nghiên cứu thuần tập (tiến cứu / hồi cứu) | Cohort study (prospective / retrospective) |
| Nghiên cứu hồi cứu | Retrospective study |
| Nghiên cứu tiến cứu | Prospective study |
| Nghiên cứu can thiệp | Interventional study |
| Thử nghiệm lâm sàng ngẫu nhiên có đối chứng | Randomised controlled trial (RCT) |
| Can thiệp không đối chứng, so sánh trước – sau | Uncontrolled before–after study |
| Nghiên cứu bán thực nghiệm | Quasi-experimental study |
| Báo cáo ca bệnh / chùm ca bệnh | Case report / case series |
| Tổng quan hệ thống / phân tích gộp | Systematic review / meta-analysis |
| Tổng quan luận điểm | Narrative review |
| Nghiên cứu định tính | Qualitative study |
| Phỏng vấn sâu / thảo luận nhóm | In-depth interview / focus group discussion |
| Nghiên cứu phương pháp hỗn hợp | Mixed-methods study |

| Hệ số tương quan | Correlation coefficient |

| Hồi quy Cox | Cox proportional hazards regression |
| Phân tích sống còn (Kaplan–Meier) | Survival analysis (Kaplan–Meier) |
| Có ý nghĩa thống kê | Statistically significant |
| Mức ý nghĩa | Significance level (α) |
| Lực mẫu | Statistical power |
| Hiệu chỉnh so sánh bội | Multiple-comparison adjustment |
| Số liệu bị thiếu | Missing data |
