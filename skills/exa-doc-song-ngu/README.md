# exa-doc-song-ngu — Đọc bài báo song ngữ Anh–Việt

[English](README_EN.md)

## Chức năng

Tạo bản đọc song ngữ Anh–Việt bám sát nguồn, căn chỉnh theo đoạn, giữ hình, bảng, công thức; hoặc trả lời câu hỏi về bài báo bằng tiếng Việt.

Lớp phủ tiếng Việt của [`nature-reader`](../nature-reader/README_EN.md): nạp skill gốc rồi áp dụng các quy tắc tiếng Việt.

## Ví dụ sử dụng

```text
Làm bản đọc song ngữ Anh–Việt cho bài báo PDF này.
```

## Quy tắc chung

- Hướng dẫn cho AI viết bằng tiếng Anh; trao đổi với người dùng bằng tiếng Việt.
- Không gửi bản thảo hoặc dữ liệu người bệnh ra dịch vụ bên ngoài.
- Không bịa số liệu, tài liệu tham khảo hay số quyết định; chỗ thiếu ghi `[CẦN BỔ SUNG: ...]`.
- Xem đầy đủ trong [AGENTS.md](../../AGENTS.md).
