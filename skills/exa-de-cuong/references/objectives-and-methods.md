## Writing objectives

Each objective is one sentence: **verb + what + in whom + where + when**.

| Verb (Vietnamese) | Use for | Design implication |
|---|---|---|
| Mô tả | Characteristics, distribution | Descriptive |
| Xác định | Prevalence, proportion, value | Descriptive with precision-based sample size |
| Phân tích / Tìm hiểu mối liên quan | Associations | Analytical; needs comparison groups or regression |
| So sánh | Differences between groups | Two-group sample size |
| Đánh giá kết quả / hiệu quả | Outcomes of an intervention | Before–after (no causal claim) or controlled design |
| Đánh giá giá trị (chẩn đoán, tiên lượng) | Test accuracy, prognostic value | Diagnostic accuracy / cohort |

Rules:
- 1–3 objectives; each must be answerable with the planned data.
- Avoid vague verbs: "nghiên cứu", "tìm hiểu một số đặc điểm" without stating what is measured.
- "Hiệu quả" claims require a comparator; otherwise use "kết quả".
- The title should reflect the objectives, population, setting, and (if relevant) period.

Example:
> Xác định tỷ lệ tăng huyết áp ẩn giấu ở người bệnh đái tháo đường type 2 điều trị ngoại trú
> tại Bệnh viện [X] năm 2026.

## Objective → design → analysis alignment

Build this table for every proposal and check it before drafting anything else:

Mismatch in any row is a Major finding in audits.

## Variables table

| Tên biến | Định nghĩa / cách đo | Loại biến | Giá trị / đơn vị | Phương pháp thu thập | Mục tiêu |
|---|---|---|---|---|---|

Define every outcome with its criterion source and year (for example a named guideline edition).
Include confounders that the analysis will adjust for.

## Methods section checklist

- Design named precisely (see glossary)
- Setting: hospital/department level, catchment, period (dd/mm/yyyy – dd/mm/yyyy)
- Inclusion and exclusion criteria, each operational and checkable
- Sample size: formula, every input with source, final n with non-response allowance
- Sampling method and how it is implemented in practice
- Data collection: instruments (validated Vietnamese version or translation procedure),
  who collects, training, pilot
- Laboratory or imaging procedures: equipment, protocol, reference values
- Data management: entry software, double entry or checks, storage, de-identification
- Analysis plan per objective: tests, models, software and version, significance level
- Reporting guideline the final report will follow (STROBE, CONSORT, STARD...)

## Bias control

List each likely bias and its control measure:

| Sai số | Nguồn | Biện pháp khống chế |
|---|---|---|
| Sai số chọn | Convenience sampling, refusal | Consecutive enrolment, record refusals |
| Sai số thông tin | Interviewer, recall | Standardised training, pre-tested tool, records over recall |
| Sai số đo lường | Equipment, observers | Calibration, inter-observer agreement |
| Nhiễu | Unmeasured confounders | Adjustment, stratification |

## Ethics section

State: committee to be approached; consent procedure (written, verbal, or waiver with
justification); confidentiality and de-identification; voluntary participation and withdrawal;
risks and their management; benefits; conflict of interest. Do not state an approval number in a
proposal; use `[Số quyết định của Hội đồng đạo đức — bổ sung sau khi được duyệt]`.

## Dummy tables

test to be used. Number them by chapter (Bảng 3.1, 3.2...). No numbers, no invented results.
